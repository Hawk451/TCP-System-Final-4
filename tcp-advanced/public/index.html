🔧 Website Integration Guide

How to connect your company website to this TCP Detection System
📋 How It Works
This TCP Detection System sits between the internet and your website. Every visitor that connects to your website is automatically routed through the TCP server first. The system checks if the IP is blocked, suspicious or malicious — and either allows them through or redirects them to a blocked page. All traffic is logged, monitored and analysed in real time on this dashboard.
1
Install Node.js on Your Server
Download and install Node.js (v18 or higher) on the server where your website will run.
Download from: https://nodejs.org
node --version   # Should show v18 or higher
2
Install MongoDB
The system stores all ping data, blocked IPs, reputation scores and learning data in MongoDB.
Download from: https://www.mongodb.com/try/download/community
Make sure MongoDB is running on port 27017 (the default).
mongod --version   # Confirm MongoDB is installed
3
Copy the TCP System Files to Your Server
Copy the entire tcp-advanced folder to your server. This contains index.js (the main system), the dashboard, and all dependencies.
cd tcp-advanced
npm install   # Install all required packages
4
Place Your Website Files in the aviation-test-site Folder
Replace the contents of the aviation-test-site folder with your own company website files (HTML, CSS, JS, images). Your website's main page must be named index.html.

The TCP system will automatically serve your website on port 8080 and protect it — no changes to your website code are needed.
5
Start the TCP Detection System
Run the main system from the tcp-advanced folder. This starts all three servers at once.
node index.js
This starts:
 • TCP Listener on port 9000 — monitors all incoming connections
 • Dashboard on port 3000 — your admin control panel
 • Your Website on port 8080 — protected and monitored
6
Log Into the Dashboard and Create Your Admin Accounts
Open your browser and go to http://localhost:3000 (or your server's IP address on port 3000).
On the very first start the system creates a Super Admin account called admin with a random password, and prints that password once in the server console.

Log in with it, then go to the ⚙️ Admin tab, change the password immediately, and add your own admin accounts.
7
Point Your Domain to Port 8080
If you have a domain name (e.g. www.yourcompany.co.za), configure your web server (Nginx or Apache) to forward traffic from port 80/443 to port 8080 where your protected website runs.

Example Nginx config:
server {
  listen 80;
  server_name www.yourcompany.co.za;
  location / {
    proxy_pass http://127.0.0.1:8080;
    proxy_set_header X-Forwarded-For $remote_addr;
  }
}
⚠️ The proxy_set_header X-Forwarded-For line is important — it makes sure the TCP system sees the real visitor IP address, not the proxy IP.
8
✅ Your Website is Now Protected
Once running, the TCP system will automatically:
 • Block malicious IPs before they reach your website
 • Detect ghost IPs (attackers switching IP addresses)
 • Learn normal traffic patterns and alert on anomalies
 • Show live alerts when suspicious activity is detected
 • Build IP reputation scores over time

Monitor everything from this dashboard in real time.
📌 Port Reference
Port 9000 TCP Listener — monitors all incoming connections
Port 3000 Admin Dashboard — login at http://localhost:3000
Port 8080 Your Protected Website
Port 8082 Web Monitor Proxy — monitor any external URL through TCP detection
